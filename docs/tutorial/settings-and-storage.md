# Шаблоны, настройки и хранение данных

## Шаблоны

Окно шаблонов открывается кнопкой **🧩 Шаблоны**.

### Встроенные шаблоны

В приложении есть пять системных шаблонов:

- **Важное сообщение**;
- **Сообщение со ссылкой**;
- **Сообщение с кодовым блоком**;
- **Сообщение с изображением**;
- **Упоминание сотрудника**.

Нажмите **Вставить**, чтобы добавить Markdown шаблона в позицию курсора. Если
в шаблоне отображаются переменные вида `{{тема}}` или `{{текст}}`, замените их
в редакторе вручную. Отдельного диалога для подстановки значений нет.

Поле **Фильтр** ищет шаблон по имени и категории.

### Пользовательский шаблон

Чтобы сохранить текущий документ:

1. Откройте **🧩 Шаблоны**.
2. В блоке **Сохранить текущий документ как шаблон** укажите имя.
3. При необходимости укажите категорию.
4. Нажмите **Сохранить**.

Сохраняется текущий Markdown и результат последней конвертации. Пользовательские
шаблоны можно вставлять и удалять; системные шаблоны удалить нельзя.

## Настройки

Окно открывается кнопкой **⚙ Настройки**. Изменения сохраняются локально
автоматически.

### Общие

- **Профиль по умолчанию** — профиль, который выбирается при запуске, если в
  сохранённой сессии ещё нет профиля.
- **Автоконвертация** — обновлять результат после каждого изменения исходника.
- **Синхронная прокрутка редактора и результата** — связывать прокрутку
  редактора с вкладками **BBCode** и **Preview**.
- **Тема** — тёмная или светлая.
- **Шрифт редактора и результата** — общий размер шрифта двух основных панелей.

### Рендеринг

- **Размеры заголовков H1–H6** — размер `[size]` для каждого уровня в
  поддерживающих его профилях. Значение `0` означает только жирное начертание.
  Значения по умолчанию: H1 — 30 px, H2 — 24 px, H3 — 20 px, H4–H6 —
  только жирный текст.
- **Размер изображений по умолчанию** — доступный выбор `small`, `medium` или
  `large`. Само изображение всё равно выводится как ссылка, а не как `[img]`,
  поэтому фактический размер нужно проверять в целевом интерфейсе.
- **Маркер списка** — `•` или `-`.
- **Стиль цитат** — доступные варианты отображения цитат; фактический вид
  результата проверяйте на вкладке **BBCode**, потому что профиль может
  использовать собственный безопасный формат.
- **Горизонтальная линия** — строка, которой заменяется Markdown-разделитель
  `---`.

### Код и предупреждения

- **Разрешить [code] в Core Safe Profile** — если включено, многострочный код
  в `Core Safe` будет заключён в `[code]`; по умолчанию опция выключена.
- **Ручная подсветка кода в preview** — параметр отображается в настройках
  предпросмотра; формат экспортируемого результата определяется выбранным
  профилем.
- **Manual Code Highlight: подсветка в BBCode без [code]** — добавлять
  цветовые токены при использовании профиля `Manual Code Highlight`.
- **Предупреждать о потере форматирования** — показывать предупреждения,
  когда профиль заменяет или удаляет часть оформления.

### Хранение

- **Автосохранение** — периодически сохранять текущий черновик и сессию.
- **Интервал, сек** — от 5 до 300 секунд.
- **Каталог хранения** — пользовательский каталог для настроек, сессии,
  автосохранения, шаблонов и списка последних файлов. Пустое значение
  использует каталог данных приложения, выбранный операционной системой.
  Чтобы переключить каталог, нажмите **Применить**. Текущая сессия,
  пользовательские шаблоны и список недавних файлов переносятся в новый каталог;
  уже существующие шаблоны и недавние файлы объединяются.

## Автосохранение и восстановление

При включённом автосохранении приложение периодически записывает состояние
сессии. При закрытии оно также сохраняет текущий Markdown, выбранный профиль и
путь открытого файла. При следующем запуске последняя сохранённая сессия
подхватывается автоматически.

В каталоге хранения используются, в частности, следующие файлы:

| Файл | Назначение |
| --- | --- |
| `settings.json` | Настройки приложения. |
| `session.json` | Последний текст, профиль и путь файла. |
| `autosave.md` | Последняя копия Markdown, записанная автосохранением. |
| `templates.json` | Пользовательские шаблоны. |
| `recent.json` | Список последних файлов. |

Автосохранение не заменяет обычное **💾 Сохранить**: для постоянной работы с
документом сохраняйте исходный `.md` в выбранное место.

## Последние файлы

Откройте меню **🕘**, чтобы быстро выбрать один из последних файлов. В список
попадает файл после открытия или сохранения; хранится не более десяти записей.
Если файл был перемещён или удалён, откройте его через **📂 Открыть** заново.

## Типичные проблемы

### Справа ничего не меняется

Проверьте, включён ли переключатель **Авто**. Если он выключен, нажмите
**⟳ Конвертировать**. Также убедитесь, что редактируется левая панель
**Markdown**, а не вкладка результата.

### Пропали цвет, размер или упоминание

Проверьте выбранный профиль. `Core Safe` и `Plain Text` намеренно удаляют
часть расширенной разметки. Откройте **Диагностика**, чтобы увидеть точную
причину замены.

### Изображение не отображается как картинка

Это ожидаемое поведение: приложение не генерирует `[img]`. Используйте URL,
проверьте его доступность и при необходимости оставьте в сообщении ссылку.
Чтобы получить отдельные файлы ресурсов, нажмите **📦 Ресурсы**: локальное
изображение будет скопировано, а внешний адрес сохранится как `.url`-ссылка.

### Код выглядит иначе

Проверьте профиль и настройки кода. `Core Safe` по умолчанию использует
отступ, `Full Message` — `[code]`, а `Manual Code Highlight` — ручное
оформление без `[code]`. Подсветка не гарантируется самим Bitrix24.

### Таблица не появилась в тексте сообщения

Нажмите **📦 Ресурсы**, выберите каталог и проверьте созданные
`table_N.xlsx`. В сообщении остаётся ссылка на этот файл, поскольку таблицы
не поддерживаются документированным BBCode Bitrix24. В этом же каталоге
появится `resources.txt` с перечнем таблиц и изображений.

### Не удаётся открыть или сохранить файл

Убедитесь, что файл доступен для чтения/записи и содержит UTF-8. Для экспорта
выберите каталог, в который у пользователя есть права. Подробная ошибка
появится в строке состояния.

### Не удалось скопировать результат

Попробуйте **📋 Копировать результат** для обычного текста или
**✨ Копировать форматированный** для HTML clipboard. Ошибка буфера обмена
отображается в строке состояния; при необходимости используйте **📤 Экспорт**
и откройте сохранённый файл.
