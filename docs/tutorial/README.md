# Руководство пользователя BitrixText Forge

BitrixText Forge — локальное настольное приложение для подготовки сообщений
в Bitrix24. Текст вводится в Markdown, приложение преобразует его в
совместимый с выбранным профилем BBCode или в обычный текст. Готовый результат
можно проверить, скопировать в буфер обмена и вручную вставить в Bitrix24.

Приложение **не подключается к Bitrix24**, не отправляет сообщения и не
запрашивает учётные данные. Все документы, настройки, черновики и шаблоны
остаются на компьютере пользователя.

## Быстрый старт

### 1. Запустите приложение

Для запуска из исходного кода нужны Rust stable и поддержка edition 2024.
В PowerShell из корня проекта выполните:

```powershell
cargo run --release
```

Для разработки и быстрой проверки изменений можно использовать:

```powershell
cargo run
```

После `cargo build --release` готовый исполняемый файл Windows находится в
`target\release\bitrixtext_forge.exe`.

### 2. Введите исходный текст

Левая панель **Markdown** — это редактор исходного документа. Например:

```markdown
# Еженедельный отчёт

**Коллеги**, добрый день!

- Закрыто **12** задач
- [ ] Проверить релиз
- [x] Отправить отчёт

Подробнее: [документация](https://example.com)
```

При включённой настройке **Авто** результат обновляется после изменения
текста. Если автоматическая конвертация отключена, нажмите
**⟳ Конвертировать** в верхней панели.

### 3. Выберите профиль

В верхней панели выберите один из профилей:

- **Bitrix24 Full Message** — расширенное форматирование;
- **Bitrix24 Core Safe** — более консервативный набор тегов;
- **Plain Text** — обычный текст без BBCode;
- **Manual Code Highlight** — полный профиль с ручным оформлением блоков
  кода.

Профиль влияет на результат, который показывается справа и копируется через
**📋 Копировать результат**. Подробное сравнение приведено в
[справке по профилям](profiles-and-export.md#профили-вывода).

### 4. Проверьте результат

На правой панели доступны вкладки:

- **BBCode** — итоговый текст, который следует копировать в Bitrix24;
- **Preview** — визуальное приближение результата;
- **Диагностика** — информационные сообщения и предупреждения о потере
  форматирования;
- **Спецвставки** — мастера для тегов Bitrix24, у которых нет удобного
  Markdown-аналога.

Предпросмотр нужен для быстрой проверки оформления, а перед отправкой
рекомендуется просмотреть именно вкладку **BBCode** и вкладку
**Диагностика**.

### 5. Скопируйте или экспортируйте результат

- **📋 Копировать результат** помещает вывод выбранного профиля в системный
  буфер обмена.
- **📤 Экспорт** сохраняет вывод в файл `.txt`, `.bbcode.txt` или `.json`.
- **💾 Сохранить** сохраняет исходный Markdown, а не сгенерированный BBCode.

Затем вставьте скопированный текст в нужное поле Bitrix24 вручную. Приложение
не выполняет вставку в браузер и не отправляет сообщение за пользователя.

## Окно приложения

### Верхняя панель

| Элемент | Назначение |
| --- | --- |
| **📄 Новый** | Очищает редактор и начинает новый документ. |
| **📂 Открыть** | Открывает `.md`, `.markdown` или `.txt` в кодировке UTF-8. |
| **🕘** | Показывает последние открытые файлы; хранится до 10 записей. |
| **💾 Сохранить** | Сохраняет исходный Markdown. Для нового документа открывает диалог выбора имени. |
| **📤 Экспорт** | Сохраняет результат текущего профиля. |
| **📋 Копировать результат** | Копирует результат текущего профиля в буфер обмена. |
| Выпадающий список профиля | Переключает способ преобразования. |
| **Авто** | Включает или выключает автоматическое обновление результата. |
| **⟳ Конвертировать** | Запускает обновление вручную, когда **Авто** выключен. |
| **🧩 Шаблоны** | Открывает встроенные и пользовательские шаблоны. |
| **➕ Спецвставки** | Переключает правую панель на мастера специальных тегов. |
| **⚙ Настройки** | Открывает параметры приложения. |

### Центральная область

Слева редактируется Markdown. Справа отображается выбранная вкладка результата.
Если включена **Синхронная прокрутка редактора и результата**, прокрутка
редактора и вкладок **BBCode**/`Preview` перемещается пропорционально.

### Строка состояния

Внизу отображаются текущий профиль, состояние черновика, статус
автосохранения, количество символов и строк, число предупреждений и последнее
сообщение об операции. Если вывод неожиданно не изменился, сначала проверьте
эту строку и нажмите **⟳ Конвертировать**.

## Обычный рабочий сценарий

1. Нажмите **📄 Новый** или откройте существующий Markdown-файл через
   **📂 Открыть**.
2. Введите или вставьте исходный текст в левую панель.
3. Выберите профиль, соответствующий месту, где будет опубликовано сообщение.
4. Откройте **Диагностика** и исправьте предупреждения, если форматирование
   критично для результата.
5. Перейдите на вкладку **BBCode** и проверьте ссылки, код, изображения и
   специальные вставки.
6. Нажмите **📋 Копировать результат** или **📤 Экспорт**.
7. Вставьте результат в Bitrix24 и проверьте его уже в интерфейсе Bitrix24
   перед отправкой.
8. Нажмите **💾 Сохранить**, если нужно сохранить исходник для повторного
   редактирования.

Если в документе есть таблицы, приложение дополнительно создаст файлы
`table_1.xlsx`, `table_2.xlsx` и т. д. рядом с сохранённым исходником или
экспортированным результатом. Подробнее см. в разделе
[Таблицы и файлы Excel](profiles-and-export.md#таблицы-и-файлы-excel).
