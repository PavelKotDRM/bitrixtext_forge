# Профили, проверка результата и экспорт

Профиль выбирается в выпадающем списке верхней панели. Он определяет, какие
теги и способы представления допустимы в итоговом тексте. Переключение профиля
сразу запускает конвертацию.

## Профили вывода

| Профиль | Что сохраняет | Когда использовать |
| --- | --- | --- |
| **Bitrix24 Full Message** | Расширенное форматирование: `[b]`, `[i]`, `[u]`, `[s]`, `[url]`, `[user]`, `[color]`, `[size]`, `[icon]`; блоки кода — через `[code]`. | Обычный выбор, если целевое поле Bitrix24 поддерживает расширенные теги. |
| **Bitrix24 Core Safe** | Базовые `[b]`, `[i]`, `[u]`, `[s]` и `[url]`. Дополнительные конструкции заменяются безопасным текстом. | Когда важна переносимость и минимальный набор разметки. |
| **Plain Text** | Только текст и структура строк; BBCode не генерируется. | Для полей, где разметка не нужна или нежелательна. |
| **Manual Code Highlight** | Возможности полного профиля, но блоки кода выводятся без контейнера `[code]`: с префиксом `>>` и, при необходимости, `[color]`-токенами. | Когда код нужно оформить вручную и проверить в конкретном интерфейсе Bitrix24. |

### Потеря форматирования в безопасных профилях

В `Core Safe`:

- `[color]` и `[size]` удаляются, текст остаётся;
- `[user]` заменяется отображаемым именем;
- `[icon]` заменяется URL;
- изображения становятся ссылками;
- код по умолчанию выводится с отступом в четыре пробела;
- inline-код выводится обычным текстом.

В `Plain Text` снимаются все BBCode-теги. Например, ссылка
`[текст](https://example.com)` становится `текст (https://example.com)`, а
изображение — `описание: https://example.com`.

### Код и ручная подсветка

Обычный `Full Message` оборачивает многострочный код в:

```text
[code]
код
[/code]
```

Bitrix24 не гарантирует подсветку синтаксиса внутри `[code]`. Профиль
`Manual Code Highlight` намеренно не использует `[code]`: код оформляется
префиксом `>>`, а настройка **Manual Code Highlight: подсветка в BBCode без
[code]** может добавить `[color=#HEX]`. Такой вывод следует проверять в
конкретном поле Bitrix24, потому что это визуальное приближение, а не
гарантированная подсветка.

## Вкладки результата

### BBCode

Это основной текст для копирования и экспорта. Его можно выделить мышью и
просмотреть как обычный текст. Вкладка не заменяет исходник: редактируйте
Markdown слева, затем снова выполните конвертацию.

### Preview

Вкладка показывает визуальное приближение поддерживаемых тегов: жирного,
курсива, подчёркивания, цвета, размера, ссылок, кода и иконок. Это не
подключение к Bitrix24 и не гарантия того, что внешний интерфейс отобразит
каждый тег точно так же.

### Диагностика

Здесь отображаются информационные сообщения и предупреждения. Особенно важно
проверять сообщения о:

- замене изображения ссылкой;
- вынесении таблицы в Excel;
- удалении цвета или размера в безопасном профиле;
- замене иконки URL;
- неподдерживаемом HTML или исключённых тегах;
- некорректных параметрах `[color]`, `[size]`, `[user]` и `[icon]`.

Количество предупреждений также показывается в строке состояния и рядом с
названием вкладки.

## Сохранение исходника и экспорт результата

### Сохранить

**💾 Сохранить** записывает Markdown, который находится слева. Поддерживаются
обычные расширения `.md` и `.txt`; при открытии также принимается
`.markdown`. Для нового документа приложение предложит имя
`сообщение.md`.

### Экспорт

**📤 Экспорт** сохраняет уже сгенерированный результат текущего профиля. В
диалоге доступны форматы:

- `.txt` — текстовый результат;
- `.bbcode.txt` — результат с BBCode;
- `.json` — исходный Markdown, результат и название профиля.

Пример структуры JSON:

```json
{
  "markdown": "# Заголовок",
  "bbcode": "[size=30][b]Заголовок[/b][/size]",
  "profile": "Bitrix24 Full Message"
}
```

Поле `bbcode` сохраняется с таким именем для всех профилей; в `Plain Text`
оно содержит обычный текстовый результат.

### Копировать результат

**📋 Копировать результат** помещает текущий вывод в системный буфер обмена.
Если буфер обмена недоступен, сообщение об ошибке появится в строке состояния;
в этом случае используйте экспорт в файл.

### Копировать форматированный текст

**✨ Копировать форматированный** помещает в буфер обмена HTML-представление
результата. Жирный, курсив, подчёркивание, зачёркивание, цвет, размер,
ссылки, код и цитаты передаются как форматированный текст. BBCode текущего
профиля сохраняется как текстовый fallback для приложений, которые не
поддерживают HTML clipboard.

URL проверяются перед добавлением в HTML-ссылки; небезопасные схемы
отображаются обычным текстом. Если приложение назначения не принимает HTML,
используйте **📋 Копировать результат** для передачи исходного BBCode.

## Таблицы и ресурсы

Bitrix24 не предоставляет документированный BBCode-тег таблицы, поэтому
таблица не встраивается в текст сообщения. Для явного экспорта нажмите
**📦 Ресурсы** и выберите каталог. Приложение:

1. создаёт в выбранном каталоге `table_1.xlsx`, `table_2.xlsx` и т. д.;
2. сохраняет строки и выравнивание ячеек;
3. оставляет в сообщении имя соответствующего файла;
4. копирует локальные изображения как `image_N.<расширение>`;
5. сохраняет внешние URL как `image_N.url`, не обращаясь к сети;
6. создаёт `resources.txt` с соответствием исходных ресурсов и файлов;
7. показывает путь и количество экспортированных ресурсов в строке состояния.

Для относительных ссылок на изображения каталог исходного Markdown-файла
используется как база поиска. Если файл не найден, сохраняется `.url`-ссылка
с исходным адресом. Если выбранный каталог недоступен для записи, проверьте
сообщение в строке состояния и выберите другой каталог.

## Как выбрать профиль на практике

- Для обычного форматированного сообщения начните с **Full Message**.
- Если результат должен пережить ограничения разных полей Bitrix24, попробуйте
  **Core Safe** и исправьте предупреждения.
- Для вставки в поле без поддержки BBCode выберите **Plain Text**.
- Для кода, который нужно оформить вручную, используйте
  **Manual Code Highlight**, но обязательно проверьте итоговый текст и
  предпросмотр в самом Bitrix24.
